# 分流配置模板

核对与验证日期：2026-11-15。

模板保存完整的分流配置：启用的内置策略组、自定义策略组及其类型和成员顺序、筛选代理组、链式代理、规则集开关、多来源规则绑定、内置规则目标覆盖、自定义规则、规则镜像及生成参数。旧模板缺少新增字段时按空值加载。

## 配置流程

1. 在“配置生成”点击“编辑分流”或“规则来源 · 多选”，打开分流编辑。
2. 在“策略组”启用内置组，或输入名称新建自定义组。可选手动选择（select）、自动测速（url-test）、故障转移（fallback）、负载均衡（load-balance）。
3. 勾选组成员，成员按勾选顺序保存；取消后重新勾选可调整顺序。“全部节点”在生成时加入当前启用的节点。测速类组使用设置中的测速 URL 与周期。按地区、关键词或订阅筛选节点可先创建筛选代理组，再将它作为策略组成员。
4. 到“规则集”按来源勾选规则，支持内置 MetaCubeX、MetaCubeX 扩展、blackmatrix7、Loyalsoldier、ACL4SSR 和手动链接同时使用。顶部来源开关可同时开启多个来源；各来源的全选和清空独立生效。未启用组的规则也完整显示，选中会启用所属组。
5. 点击每条规则右侧蓝色目标，选择内置组、自定义组或 DIRECT / REJECT / REJECT-DROP。选择未启用的内置组会同时启用该组；选择外部规则时也会启用对应默认服务组。不会悄悄改绑到“节点选择”。
6. 在“自定义规则”填写 Mihomo 规则，例如 `DOMAIN-SUFFIX,example.com,流媒体专线`。目标必须存在。
7. 分流修改每两秒自动保存并更新有效输出，收起或切页无需确认。在底部填写名称后点击“存为模板”（编辑已有模板时为“更新模板”），可在模板页再次恢复。内置地区组已移除，旧地区目标迁移至“节点选择”；手动创建的同名自定义组继续保留。生成页“保存新配置”另外保存一份独立 YAML，可在“我的配置”中编辑更新。

例如可把内置 Netflix 域名规则、blackmatrix7 的 Netflix 规则和 ACL4SSR 的 Netflix 规则都绑定到“流媒体专线”，把 Netflix IP 规则绑定到“测速专线”。规则按生成的 YAML 顺序匹配；重叠的规则以先命中的为准。希望使用某个来源替代内置规则时，应关闭对应内置规则。

## 校验与错误处理

自动保存或保存模板前先在独立配置中完整生成和校验，再更新当前配置。组名不得为空、包含逗号或换行，或与现有组、节点、保留策略重名。空成员、未知目标、自引用和间接循环均报错；被规则或其他组引用的自定义组不能直接删除。无效模板不会部分覆盖当前配置。

新策略组的成员可选择其他组、内置策略与全部节点；精确的节点筛选沿用主页面的筛选代理组。链式代理沿用专门的链式配置入口。

## 已保存配置的可视化编辑

「我的配置」打开后默认进入可视化编辑，不再把 YAML 预览作为主界面。节点、策略组、规则和 Mihomo 运行参数分别编辑，修改自动保存到当前配置的独立 YAML 文件。YAML 页只用于高级字段和未识别结构。

规则页从策略组进入时自动锁定当前目标；关闭来源或单条规则后，返回策略组立即刷新规则数量。来源开关只影响当前目标，切换到另一个策略组不会把规则误删或误显示。策略组停用会保留成员、规则和引用，重新启用即可恢复。
