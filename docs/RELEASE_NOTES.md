# SwiftSub v0.1.0 验收与发布说明

验收日期：2026-11-14。适用平台：Windows x64。此文件记录五批功能开发及后续布局优化后的本地产物，不表示已发布 GitHub Release。

## 本轮功能

- 可调节点 / 编辑器 / 预览布局，面板收起、固定底部操作、搜索快捷键。
- 多来源规则同时选择，按来源分类、搜索、仅已选和目标筛选；内置及自定义策略组、成员排序、测速参数、规则排序和引用 / 循环 / 冲突诊断。
- 完整分流模板的创建、编辑、复制、重命名、版本化导入导出；草稿预览、定时保存和重启恢复；配置、模板和设置同事务提交。
- 节点逐项导入报告、配置追溯报告与摘要；失败刷新保留成功内容；更新 REALITY / XHTTP 分享链接字段映射。
- 2–16 跳链路、独立 mixed/http/socks 监听、高级 DNS / YAML；SSR、AnyTLS、Snell、SSH、WireGuard 链接解析。
- 多配置独立规则、来源成员和订阅地址，同时提供各配置输出；订阅缓存和节点编辑共享。
- 订阅及节点 YAML 二维码、SVG 导出、Windows 托盘、关闭后隐藏及默认关闭的用户级自启开关。

## 布局更新

- 分流编辑精简头部，底部固定模板名称与应用操作；规则集筛选集中，链接输入按需展开。
- 节点信息分行；较窄窗口将当前输出预览放在编辑器下方，宽窗口采用右侧预览。
- 高级 JSON 与自定义规则输入使用剩余空间；预览标题、统计和操作避免窄栏重叠。
- 设置拆分为五个分类，窄窗口采用顶部分类导航；当前配置与订阅成员更清楚。

- Mihomo v1.19.34 `-t`：多来源规则与策略组配置、扩展协议 / 三跳 / 监听 / DNS 示例配置通过。

## 使用与产物

解压运行 `swiftsub.exe`。数据默认保存于 `%APPDATA%\SwiftSub`；发布包不包含 QA 数据库、订阅、凭据或测试密钥。已有数据由应用读取，建议保留原数据备份。

高级 JSON 编辑后先点「校验并更新草稿」，再应用。扩展示例与多配置行为见 [扩展配置](EXTENSIONS.md)，模板流程见 [分流模板](ROUTING_TEMPLATES.md)。本地订阅地址只供同机客户端访问。节点二维码包含代理认证信息，内容为 YAML，其他客户端是否接受这种扫码格式取决于客户端实现。

本地发布包为 `SwiftSub-v0.1.0-layout-windows-x64.zip`。可执行文件 35,730,944 字节，SHA-256：

## 验证边界

新增协议尚未逐一连接真实公网服务端；高级配置的结构校验不替代目标客户端的校验与连接测试。未穷举旧内核、全部 XHTTP 模式、多 DPI 及开机登录场景；自启没有在 QA 中开启。显式 `support-x25519mlkem768=false` 按链接保留，不能保证适配本次测试的新版服务端。

最初项目计划中的启动、内存、安装包体积目标是规划指标。本轮记录没有完整测量这些指标；压缩包的实际大小见下载文件属性。
