# SwiftSub v0.1.0 验收与发布说明

验收日期：2026-11-15。平台：Windows x64。此文件记录本地产物，不表示已创建 GitHub Release。

## 本次更新

- 新增「我的配置」。生成页「保存新配置」每次新增独立记录和 YAML 文件；列表中可改名、编辑 YAML、更新当前记录、另存一份、复制、导出和删除。
- 保存记录保留原生成设置，可重新载入生成器，再明确选择「更新原配置」或「保存新配置」。更新完成即退出原记录更新状态。
- 每份 YAML 有独立本地订阅地址。切换工作区、共享来源刷新及自动生成不会改写保存记录；更新只改变当前记录，删除后该地址返回 404。
- 内置地区策略组及分类已移除，旧地区选择和目标自动迁移至节点选择；手工创建的同名组保留。节点地区标签与自定义筛选仍可使用。
- 分流编辑每两秒自动校验保存有效修改，收起 / 切页立即保存，无需应用或确认放弃。无效或未完成的文本保留供下次继续，维持上一份有效输出。
- 延续窄窗口上下预览、宽窗口右侧预览、固定底部操作、设置分类导航等布局优化。

## 数据与文件

默认数据目录 `%APPDATA%\SwiftSub`。每条记录的正文写入 `configs/<独立ID>.yaml`，名称、正文和原生成设置存入 SQLite；同名记录也使用独立文件。启动时修复缺失文件，迁移数据库后重建保存文件。

数据库升级到 schema v3，会将各现有配置最后一份非空 YAML 迁入列表。以前已被覆盖的历史正文无法从现有数据库恢复。未提交的 YAML 编辑内容单独持久化；只有「更新此配置」才替换记录和文件。格式检查、SQL 或文件写入失败时保留原有内容。

## 验收结果

- workspace 68 项测试通过，覆盖旧库升级、同名多份、更新隔离、重开、文件重建、SQL / 文件失败回滚、地区组移除及旧引用迁移；格式检查和 Git 差异检查通过。
- 实际 Windows 窗口检查默认及最小尺寸布局。保存、另存、原生成设置重载、仅更新原记录、删除和自动保存后直接切页均完成实机操作。
- 保存文件与对应 HTTP 输出逐字节一致；重新生成不改变旧文件；删除对应地址返回 404。最终 release 重启后全部保存记录及地址内容保持一致，`/health` 返回 200 / ok。
- 名称 / YAML 文字输入的键盘自动化受窗口焦点限制未完成，文本格式检查和存储更新通过测试覆盖；YAML 检查不等于连接真实代理服务端验证。
- 2026-11-14 的 Mihomo v1.19.34 语法检查与 Xray v26.11.9 受控传输结果继续见 [链接适配](LINK_COMPATIBILITY.md)，本次没有重新进行协议连接测试。

## 使用与产物

解压运行 `swiftsub.exe`。先在生成页编辑，再点击「保存新配置」；日后在「我的配置」更新所需记录。文件保存在界面底部显示的实际路径，也可导出到其他目录。

发布包 `SwiftSub-v0.1.0-my-configs-windows-x64.zip`。可执行文件 35,952,128 字节，SHA-256：

```text
524CA20582FC1552A736556E848059312DB97A3C08765A45D18ABFCDB99C3149
```

发布包不含数据库、订阅凭据及测试密钥。本地订阅地址供同机客户端使用。扩展配置见 [EXTENSIONS.md](EXTENSIONS.md)，模板流程见 [ROUTING_TEMPLATES.md](ROUTING_TEMPLATES.md)。

新增协议的公网服务端、旧内核、其他 DPI 及开机自启场景尚未穷举；桌面自启在 QA 中保持关闭。
