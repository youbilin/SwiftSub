# 手绘界面实施记录

日期：2026-11-26。当前界面以项目根目录的五张手绘图为准，并纳入完整 DNS、规则更新与每配置独立订阅的要求。

## 页面与操作

- 主导航为「生成 / 配置 / 设置」。生成页顶部为「保存 / 存为新配置」；打开已保存配置后增加「导入到 Clash Verge」。左侧添加并管理节点，右侧为策略组、链式和 DNS 覆写。
- 「保存」保留临时编辑状态，同时更新当前配置的 YAML 文件与本地订阅；首次保存自动创建配置。无效草稿保留上次有效输出。「存为新配置」填写名称后创建另一份独立文件和地址。
- 链式入口和出口下拉选择节点，默认名称随两端选择变化，也可自行命名。保存后显示在链式和左侧节点列表；编辑恢复两端并更新原链路，保留原位置、停用状态及引用。
- 策略组展开后切换「节点 / 规则」，新增规则支持搜索内置规则集、自定义链接与手写规则。
- 节点、策略组、链式节点和规则使用删除、编辑图标与开关。删除立即生效并修复相关引用；DIRECT 等系统成员省略无效编辑入口。停用对象仍可编辑。
- 内置与自定义策略组均可修改名称。改名保留内置组身份，同步规则目标、组成员、监听器和节点的 `dialer-proxy`；恢复默认参数保留新名称。
- 节点、链式、策略组和组内成员可上下移动或拖动排序，拖动时显示插入边框。普通节点与链式节点可混排，内置、自定义与筛选策略组使用统一排序。
- 展开的策略组使用突出外框、标题底色和独立子项容器，节点、规则行增加边框与底色；卡片保留所需高度，避免展开后裁切其他组。
- 配置页卡片展示当前配置、类型、节点/组/规则数量和更新时间。点击编辑后使用生成页式布局，保留保存、另存与导入；普通 YAML 保留 providers、复杂规则及未知扩展字段。另存弹窗默认使用「原名称 副本」。
- 设置页为「基础与DNS / 规则来源 / 模板 / 关于」。关于页只展示各配置本地订阅，不再显示更多设置、数据管理或桌面附加工具；深浅外观切换移到设置页右侧图标。

## 完整 DNS 与规则更新

「基础与DNS」提供表单和 YAML 双模式，覆盖 DNS 开关、监听、IPv6、Fake IP 两种地址段、过滤模式、HTTP/3、respect-rules、Hosts 开关、系统 Hosts、直连策略、各类 DNS 地址、nameserver-policy、proxy-server-nameserver-policy、fallback-filter 与根级 `hosts`。模式切换、保存和重启保留完整配置及未知扩展字段；验证错误显示在分区顶部。

规则来源提供「更新内置规则」，下载当前与已保存配置使用的规则；无已使用规则时更新核心目录。缓存按规则 ID、来源 URL 和 behavior 区分并持久化，失败保留旧内容和最近成功时间，自定义正文及草稿保持原内容。成功完整更新后，运行期间满 24 小时可再次自动更新；远程 rule-provider 保留 86400 秒客户端更新周期。

## 文件、订阅与引用

每份配置使用独立 ID，对应 `configs/<ID>.yaml` 和 `http://127.0.0.1:<端口>/sub/<ID>/<ID>.yaml`。保存立即发布当前记录，修改名称保持地址，另存创建新 ID。端口持久化，重启沿用；删除配置撤销对应文件和地址，其他配置不变。

每份生成配置分别保留节点字段、启用状态、删除记录、节点与链式混排顺序、策略组顺序和未完成编辑。切换和重启恢复自己的草稿。重命名及相关节点、策略组、规则、监听器和链式引用在同一事务保存；失败恢复原状态。停用对象保留编辑数据，删除时修复引用，避免无效目标或循环依赖。

Clash Verge 导入使用官方 `clash://install-config`，优先 `clash://`，兼容 `clash-verge://`。配置名先编码，嵌套地址放在最后一个参数，发送前保存并发布。发送后观察真实 GET/304 读取及当前 ETag，未读取时显示具体原因和配置地址。

SwiftSub 保存后立即提供最新有效内容，客户端通过手动更新或订阅周期读取；本地订阅返回 1 小时更新周期。来源刷新更新缓存，再次保存目标配置发布新内容。程序运行或隐藏到托盘时提供本地订阅。
