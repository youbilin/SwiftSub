# 配置生成页：保存与导入

本文为先前版本的实施记录。当前界面和保存行为已按五张手绘图调整，见 [手绘界面实施记录](HAND_DRAWN_UI_REDESIGN.md)。

日期：2026-11-26。按最新要求，核心流程为添加节点、调整分流，然后保存到我的配置或导入 Clash Verge。

## 页面与操作

- 顶部显示预览、保存到我的配置、导入 Clash Verge和更多，移除生成页导出；复制 YAML 保留在更多菜单。
- 首次保存在当前页填写名称，自动聚焦，回车提交，取消或 Esc 收起；再次点击保存不会重置正在填写的名称。
- 保存后留在生成页。本次编辑期间再次保存或导入会更新同一份配置，不重复新建；更多菜单提供查看已保存配置、修改名称和另存入口。
- 直接导入无需先展开保存表单；使用当前填写的名称或自动名称，先保存独立配置，再发送给 Clash Verge。导入成功提示只代表已发送客户端，不代表客户端已完成加载。
- 两条路径都校验当前策略组和规则，并从当前启用节点重新生成。没有启用节点时禁用完成按钮，不会把模板校验节点或旧预览保存成用户配置。
- 保存或导入错误完整显示在操作区下方。失败保留命名输入；客户端未安装、未启用链接关联或本地服务启动失败时，已保存配置仍可在我的配置找到。
- 更新时检查已保存配置是否被修改、删除或存在未完成的 YAML / 可视化草稿，拒绝悄悄覆盖；用户可以处理原编辑或另存一份。
- 切换工作区或删除关联配置时解除本次保存关联，避免更新错误的配置。

## 编辑细节

- 预览去掉订阅地址与重复复制入口。打开预览时先应用策略组参数；配置有误或规则正文尚未保存时，明确说明展示的是之前的内容。
- 节点尚未启用时提示启用现有节点；没有节点时才提供添加入口。
- 节点筛选无结果时就地提供清除筛选；常用节点、成员、规则添加与正文编辑继续直接使用。
- 节点面板显示 / 收起不再被无关的组参数错误阻挡。切换编辑类型仍先处理当前组参数。
- DNS、测速默认值和已有页面位置保持原约定，不增加一级页面。
