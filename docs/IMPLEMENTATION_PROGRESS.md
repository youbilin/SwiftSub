## 第一批

已实现生成页节点、编辑器与预览三栏，可拖动调整宽度，节点和预览可独立收起。分流编辑在生成页内打开，底部操作固定，草稿状态可见；新增筛选与链式入口。窄节点栏使用两行信息，预览操作支持换行。Windows 主线程栈预留改为 8 MiB，修复 debug 内嵌编辑器启动栈溢出。

验证：workspace 51 个测试通过；debug 启动与真实窗口截图验证三栏及编辑器固定操作。后续批次继续完善策略组详情、来源筛选、键盘交互和草稿离开确认。当前筛选/链式的具体编辑仍使用原有弹窗。

## 第二批

新增策略组列表 / 详情可调分栏。内置组可覆盖类型、成员、测速 URL/间隔并恢复默认；自定义组重命名会同步规则集、自定义规则和其他组引用。成员可搜索、批量加入、逐项移除、拖动和上下排序，支持动态全部节点。

最终规则页展示真实生成顺序，支持拖动 / 上下调整和恢复默认；顺序随模板和设置保存。生成器报告完全重复、相同匹配条件的不同目标、MATCH 后不可达规则；这里只分析配置规则本身，不推断远程规则集内容的交集。重复的完整规则合并保留首项。

验证：新增内置覆盖、参数、重复覆盖、排序、冲突及不可达回归；workspace 53 项测试通过；真实窗口验证内置自动组详情。SubBoost 官方源码的 proxy-groups.ts 已核对：它将模块组、成员覆盖、规则目标和 ruleOrder 作为独立但关联的配置保存，本批采用对应机制。

## 第三批

模板库支持编辑、原位更新、重命名、复制及版本 1 JSON 导入 / 导出。导入和编辑先进入草稿，显示变更分类与配置行增删；最终规则排序独立检查。新建或更新模板与当前路由设置采用同一个 SQLite 事务，失败不会切换活动配置。筛选组和链式编辑也被纳入草稿，刷新不会提前发布这些更改，取消会恢复。

离开编辑器时阻止页面切换；取消需再次点击放弃。当前这是页面内草稿保护，应用进程关闭后的自动草稿恢复仍待后续桌面生命周期批次处理。

验证：workspace 55 项测试通过，包含注入数据库写失败并检查模板及设置一起回滚、未知格式 / 版本拒绝和旧模板兼容。真实窗口完成新建保存、复制、编辑重命名并原位更新，数据库 ID 保持不变。差异预览按行内容集合展示，不对重复行位置作精确差异分析，顺序由规则页检查。

## 第四批

新增逐节点解析报告、生成配置的节点 / 规则 / 组追溯及正文 SHA-256；生成页诊断窗口可查看并导出完整 JSON。无效规则附加选项直接拒绝。远程刷新解析失败、零可用节点及写入失败时保留原成功内容。

验证：workspace 58 项测试通过；四来源 + 26 providers + 4 种策略组 / 内置覆盖通过 Mihomo v1.19.34 `-t`。真实窗口检查诊断，重启恢复模板配置。debug 合成生成基准：100 / 1000 / 10000 节点约 6 / 44 / 433 ms（单次观测，不代表界面滚动性能）。

完成受控实际传输：Xray v26.11.9 + Mihomo v1.19.34，XHTTP、RAW+REALITY true、XHTTP+REALITY true 成功读取目标 HTTP 内容；显式 MLKEM false 在该新版服务端失败。复现脚本与完整限制见 LINK_COMPATIBILITY.md。公网、旧版 Xray、全部 XHTTP 模式及多个 DPI / 系统主题尚未穷举。

## 第五批 B：多配置

设置页支持复制新配置、切换、重命名和二次确认删除。规则、DNS、链路、监听、订阅成员和文件名按配置保存；来源缓存及节点编辑共享。所有配置令牌同时服务，失效配置返回 503，删除后的令牌返回 404。

验证：workspace 62 项测试通过，新增多令牌隔离、删除失效及独立数据库记录测试。真实窗口创建第二配置并取消全部订阅后，第一配置地址仍返回 200 / 12712 字节，第二配置地址返回 503；切换回第一配置成功。


## 第五批 C：桌面交互与分享

设置页新增 Windows 托盘状态、关闭窗口隐藏到托盘、开机自启开关。托盘菜单支持打开窗口、复制当前订阅地址、刷新全部订阅和退出；自启写入当前用户 Run 项，默认关闭。模板草稿每两秒保存到 SQLite，关闭窗口前保存，重启会恢复为待应用草稿。

订阅地址和节点 YAML 支持二维码查看、复制内容及 SVG 导出。二维码窗口提示本地地址的访问范围及节点凭据风险。规则集配置支持仅显示已选项和按策略组目标筛选，仍按来源折叠显示。

验证：workspace 62 项测试通过，debug 应用构建成功；真实 Windows 窗口检查设置布局、二维码显示与 QR 解码（解码值与本地订阅 URL 一致）；发送窗口关闭消息后窗口隐藏，本地 `/health` 仍返回 `ok`。托盘事件依赖 Windows 消息循环，未在 CI 环境模拟右键菜单点击。
